# Online POS Folder

This folder is the online deployment copy for Hidden Oasis POS.

Use it with:

```text
/Users/carylmoraleda/accounting-program-online
```

Live URLs:

```text
POS frontend: https://pos.hiddenoasis.app
POS API:      https://pos.hiddenoasis.app/api
```

Server path:

```text
/opt/pos-cloud-online
```

The online POS defaults to connecting to:

```text
https://accounting.hiddenoasis.app/api
```

The root `https://hiddenoasis.app` is reserved for the future launcher and must not be used as the Accounting API base.
